# 大一大二 CS 竞赛与自学体系索引指南

![晴空星盘](./assets/set01-cover-sky-map.jpg)

> **副标题**：*从 C 语言破冰、算法底盘、系统与架构启蒙到多赛道跨界的可执行路线与资源鉴选指南*
>
> **一句话核心价值**：帮计算机及相关理工科大一、大二同学避开“收藏夹吃灰、死啃砖头书、盲目凑比赛”三大弯路，按前置依赖理清前两年最具正反馈的核心能力，配齐可裁剪资源与开箱即练的 40+4 道梯度母题。

## 一、全书三大核心特色

大一大二每天可自由支配的专注时间通常只有 **1.5~3 小时**。本书围绕三项工程原则构建：

1. **前置依赖图（DAG）导航，告别死板年级时间表**：各校开课顺序与个人起步时间不同。全书不按“大一上 X 月、大一下 Y 月”一刀切，而是按 **前置条件 → 核心能力节点 → 解锁下游** 组织知识树——无论零基础入学还是大一下、大二追赶，找准当前坐标即可看清下一步发力点。
2. **“四要素可用性卡片”鉴选，拒绝空降神书劝退**：每门推荐课程、书籍、平台与开源项目均拆解 **① 定位与前置、② 为何选它与错位神书辨析、③ 精准章节/Lab 裁剪读法与耗时、④ 劝退点与平滑替代**——讲透为何大一别逐页通读《C Primer Plus》、别拿《C++ Primer》当算法入门、别零基础硬啃《算法导论（CLRS）》或全套南大 PA，以及做 CS61B 为何必须锁定公开评测的 `sp21` 版。
3. **配套 40+4 道 `algo-coach`（`v0.2.1`）可导入梯度题单**：[`./problem-lists/`](./problem-lists/README.md) 随附洛谷、Codeforces、AtCoder、力扣中国严选的 **4 套 × 10 道母题**（外加 **4 道 CSES 拓展题**），提供零依赖一键入库脚本与按需水合缓存，在 VS Code 侧栏直通“导题 → 手写 → 评测 → 间隔复习”闭环。

## 四、一分钟上手：将 40 道配套母题导入 VS Code

启用本仓库 **Algo Coach（`v0.2.1`）** 扩展后，在仓库根目录终端执行以下命令，即可将[第 7 章](./07-算法实战训练与作业精选.md)的 40 道母题静默导入侧栏 **选题 → 已存**（四通路说明见 [`./problem-lists/README.md`](./problem-lists/README.md)）：

```bash
# 1. 预览本机 VS Code 全局缓存路径（--dry-run 不写文件）
node cs-guidebook/problem-lists/import-to-algo-coach.mjs --all --dry-run

# 2. 一次性将 40 道母题静默写入缓存（或用 --set set1 按套导入）
node cs-guidebook/problem-lists/import-to-algo-coach.mjs --all
```

导入后按 `Ctrl+Shift+P` 执行 **`Developer: Reload Window`**，在侧栏点击任意题目即可自动拉取官方题面与样例，从第一道绿灯（Accepted）稳步启航。
