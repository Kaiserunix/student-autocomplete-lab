# CSES 1068 - Weird Algorithm
- 难度：入门
- 标签：模拟，边界条件，CS-Guidebook，CSES
- 链接：https://cses.fi/problemset/task/1068
- 时间限制：1000ms
- 内存限制：512MB

## 题目描述
给定一个正整数 n，重复执行奇偶变换规则：若 n 为偶数则除以 2，若为奇数则乘以 3 再加 1，直到 n 变为 1 为止，按顺序输出每一步的值。本题用于检验循环终止控制与整型溢出意识。

## 输入格式
输入一行，包含单个正整数 n（1 <= n <= 10^6）。

## 输出格式
输出一行若干个整数，以空格分隔，依次表示从初始值 n 到 1 的变换序列。

## 提示
虽然初始 n 不超过 10^6，但在 3n+1 迭代过程中某些中间值会突破 32 位有符号整数上限（例如 n=113383 附近），C/C++ 必须使用 64 位整数类型（long long）存储 n。

## 样例输入 1
```
6
```

## 样例输出 1
```
6 3 10 5 16 8 4 2 1
```
