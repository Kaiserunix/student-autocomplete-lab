# CSES 1648 - Dynamic Range Sum Queries
- 难度：普及+
- 标签：树状数组，线段树，区间查询，CS-Guidebook，CSES
- 链接：https://cses.fi/problemset/task/1648
- 时间限制：1000ms
- 内存限制：512MB

## 题目描述
维护一个长度为 n 的动态数组并处理 q 次操作：操作 1 将 1-based 位置 k 的值修改为 u；操作 2 查询闭区间 [a, b] 内所有元素的总和。

## 输入格式
第一行包含两个整数 n 和 q；第二行包含 n 个初始整数；随后 q 行每行给出形如 1 k u 或 2 a b 的操作指令。

## 输出格式
针对每条操作 2，单独输出一行区间和结果。

## 提示
使用树状数组（单点增量更新 delta = u - cur[k]）或线段树均可实现单次操作 O(log n)；单个元素可达 10^9，区间和必须使用 64 位整数（long long）防溢出。

## 样例输入 1
```
4 3
1 4 2 5
2 1 3
1 2 9
2 1 3
```

## 样例输出 1
```
7
12
```
