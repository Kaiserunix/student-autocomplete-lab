# CSES 1633 - Dice Combinations
- 难度：普及-
- 标签：动态规划，计数DP，CS-Guidebook，CSES
- 链接：https://cses.fi/problemset/task/1633
- 时间限制：1000ms
- 内存限制：512MB

## 题目描述
通过多次投掷标准六面骰子（每次点数为 1 到 6），统计凑出总和恰好为 n 的有序投掷方案数，结果对 10^9 + 7 取模。

## 输入格式
输入一行，包含单个正整数 n（1 <= n <= 10^6）。

## 输出格式
输出一个整数，表示合法方案总数模 10^9 + 7 的结果。

## 提示
设 dp[s] 为凑出点数和 s 的方案数，初始化 dp[0] = 1，对每个 s 枚举最后一次掷出的点数 k（1..6 且 s >= k）累加 dp[s - k] 并及时取模；注意取模运算与计数顺序（排列而非组合）。

## 样例输入 1
```
4
```

## 样例输出 1
```
8
```
